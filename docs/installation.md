# Installation

SteelAnts Livewire-Form is installed using Composer.


## Requirements

- Laravel 11 or 12
- Livewire 2 or 3

The steelants/form package is installed automatically as a dependency and provides the underlying form elements.


## Install the Package

Install the package using Composer:

```bash
composer require steelants/livewire-form
```

Laravel automatically discovers the service provider.

Currently the package does not require additional configuration files.
